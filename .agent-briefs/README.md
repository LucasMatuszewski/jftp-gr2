# Historical Repomix review briefs

These briefs record the assignments and raw-text transport used for the original
full/compressed comparison, before the startup descriptor refresh. They are
supporting material for `docs/RepoMix/COMPARISON.md` and the two Luna reports.

`luna-preload.exec.js` contains byte ranges for the original files and depends on
an ignored, session-local chunk plan. It is not a runnable refresh script for the
current packs. The current hashes, sizes and file scope are recorded under
`docs/RepoMix/`; use the documented generation workflow for new snapshots.
